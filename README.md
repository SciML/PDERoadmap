# PDERoadmap

A repository for the discussion of PDE (Partial Differential Equation) tooling in the SciML ecosystem.

This repository contains examples, tutorials, and documentation for solving PDEs using DiffEqOperators and related tools. It serves as a roadmap and reference for PDE solving capabilities in Julia.

## Contents

- **[DiffEqOperators.md](DiffEqOperators.md)** - Basic tutorial on using DiffEqOperators for PDE discretization
- **[HeatEquation.md](HeatEquation.md)** - Tutorial on solving the heat equation with Dirichlet boundary conditions
- **[KdV.md](KdV.md)** - Tutorial on solving the Korteweg-de Vries equation with periodic boundaries
- **[BellmanDiffusion.md](BellmanDiffusion.md)** - Tutorial on solving the Bellman equation with diffusion
- **operator_examples/** - Julia code examples demonstrating various operators and boundary conditions
- **transition_dynamics_examples/** - Examples of transition dynamics problems
